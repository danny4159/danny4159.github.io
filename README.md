# Daniel Kim — Academic Homepage

A minimal, responsive academic homepage, built with plain HTML and CSS. No dependencies or build tools required.

## Publish on GitHub Pages

1. Sign in to GitHub with the account you want to use. If the username is `danny4159`, create a **public** repository called **`danny4159.github.io`**. If your username differs, replace the name accordingly.
2. Upload `index.html`, `styles.css`, `favicon.svg`, and `.nojekyll` to the root directory of the new repository, then commit the changes.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select the **main** branch and **/(root)** folder, and click **Save**.
5. Open `https://danny4159.github.io` once the site is published (or use your GitHub username).

Official setup instructions: https://docs.github.com/en/pages/quickstart

## Edit content

- **Name, affiliation and research summary**: `index.html`, near the top of `<aside>` and `<header class="intro">`.
- **Publication details and links**: the `<article class="publication">` blocks in `index.html`.
- **Contact information**: the email links and `#contact` section in `index.html`. The currently inserted address is the publicly listed Yonsei email in the author's published record; change it if you prefer another address.
- **Appearance**: edit the color variables in `styles.css` under `:root`.
- **Profile photo**: intentionally omitted to keep the site clean; it can be added later.
